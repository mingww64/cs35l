
Added Functions:
Move count (moveCount): number to track placed pieces

countPlayerPieces(NextMoves):

- Counts how many pieces a player has on board

- Used to determine game phase (rule 1)

isAdjacent(from, to):

- Checks if two squares are adjacent

- Uses predefined adjacency map 

- Returns true if squares are neighbors

mustMoveFromCenter(player):

- Checks if player must move from center

- Tests for possible winning moves, return winning move if exists

- Returns true if center piece must move (no winning move and center occupied by the player)
